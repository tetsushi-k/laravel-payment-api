# Personas — React SPA 化

## P-1: テストユーザー（一般購入者）

| 項目 | 内容 |
|---|---|
| **名前** | テストユーザー |
| **役割** | ログイン済みの一般購入者 |
| **目的** | カード決済を行い、自分の注文履歴を確認する |
| **技術リテラシー** | 一般的な Web ユーザー（SPA の存在は意識しない） |
| **利用環境** | ブラウザ（`http://localhost`）、Stripe テストカード |
| **認証情報** | `test@example.com` / `password123`（Seeder 投入） |

**主なニーズ**
- すぐにログインして決済できる
- 決済結果が注文一覧で確認できる
- 他人の注文は見えない

**フラストレーション要因**
- ログインできない / エラーがわかりにくい
- 決済後にステータスが更新されない（Webhook 遅延時に再取得方法が不明）

**関連ストーリー**: US-001〜US-009, US-011

## P-2: Stripe（外部決済システム）

| 項目 | 内容 |
|---|---|
| **名前** | Stripe |
| **役割** | 決済処理と Webhook 通知を行う外部システム |
| **目的** | カード決済を処理し、結果をサーバーへ非同期通知する |
| **技術リテラシー** | API / Webhook 連携（システムアクター） |
| **利用環境** | Stripe API、Stripe CLI（ローカル開発） |

**主なニーズ**
- PaymentIntent 作成 API への正しいリクエスト
- Webhook 受信後に 200 を返す（リトライ抑制）
- 署名検証済みのエンドポイント

**関連ストーリー**: US-005（同期側）, US-010（非同期 Webhook）
